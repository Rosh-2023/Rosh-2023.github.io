## A consistent format for each tutorial

Each tutorial will aim to include:

1. A plain-language explanation of the physical concept.
2. The key equations, with variables and units explained.
3. A diagram or worked example.
4. A small Python notebook or script.
5. A short exercise and suggested further reading.

When code is available, link to the notebook on GitHub and, where practical, provide a **Run in Google Colab** or **Launch Binder** link. Make sure external notebooks are public and do not contain credentials or private data.
